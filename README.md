# Auto Dev Setup

Automatically sets up the following:
- Bash aliases
- Tmux config
- [KeVim Neovim config](https://github.com/kfalcetano/kevim)

Just clone this repo (generally to the home dir) and run `setmeup.sh`

> [!NOTE]
> This does not install any dependencies

## Required dependencies

- [exa](https://github.com/ogham/exa)
- [tmux](https://github.com/tmux/tmux)
- [fzf](https://github.com/junegunn/fzf)
- [Neovim](https://github.com/neovim/neovim)
  - `:checkhealth` for plugin dependencies

## Terminal Preferences

### Font

[**FiraCode Nerd Font**](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/FiraCode.zip)

### Terminal Emulator

#### Windows 

[Microsoft Terminal](https://github.com/microsoft/terminal)

Built in to Windows 11 but also can be installed as a separate app, it's cool when Microsoft puts care into their apps. The team behind Terminal definitely did.

#### macOS / Linux

[Ghostty](https://ghostty.org/)

Fast, supports ligatures, has windowing and tab features but they stay out of the way of a tmux workflow. It's nice.
